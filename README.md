
# WpfVodovoz

WPF приложение с использованием MVVM, NHibernate и DI.

## Требования

Перед запуском необходимо установить:

- .NET 6/7/8 SDK
- Docker Desktop
- SQL Server (запускается в контейнере)

---

##  Запуск проекта

### 1. Поднять базу данных в Docker

В корне проекта выполните:

```bash
docker-compose up -d
### 2. Запустить проект
Start (F5)
